# Security

Report a vulnerability privately, through GitHub's "Report a vulnerability" button on the Security tab of https://github.com/kelchm/scrobl. Please do not open a public issue.

What counts:

- Anything that could expose an API key, an API secret or a session key, in a log, an error, a `Debug` output, a URL or a request sent to the wrong place.
- Anything that could cause a write to a Last.fm account that the caller did not ask for, including a repeated scrobble.

Only the latest version is supported.
